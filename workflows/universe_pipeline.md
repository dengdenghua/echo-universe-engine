# Universe Pipeline

ECHO Universe is meant to grow for 3-5 years. The goal is not to write one story quickly. The goal is to build a repeatable universe production mechanism similar to long-running IP systems.

## Principle

Canon first. Story second. Assets third.

Every generated item must pass through:

```text
Idea
Candidate output
Consistency check
Canon promotion
Timeline / relationship / faction update
Asset task generation
```

## Stage 1: Month 1, Universe Bible V1.0

Goal: complete the first stable Universe Bible.

Outputs:

- World overview, about 100 pages
- World history
- Technology system
- AI system
- Ghost system
- Map system
- Economy system
- Organization system

Faction target: 10 factions, each eventually 10-20 pages.

Initial faction list:

- ECHO Council
- CHASER
- Ghost Union
- Black Market
- Atlas Corporation
- Church of Fragments
- Dream Network
- Memory Bank
- White Harbor
- Abyss Alliance

Character target: 50 characters.

```text
S-rank protagonists: 10
A-rank major characters: 20
B-rank supporting characters: 20
```

Each character needs:

- Illustration prompt
- Background
- Relationships
- Ability / limitation
- Quotes
- Canon risks
- Identity states
- Agent memory hooks
- Relationship weights

Detailed expansion rules:

```text
workflows/character_expansion_rules.md
```

## Stage 2: Month 3, ECHO Chronicle

Goal: build a 2025-2200 timeline.

Every year should eventually have at least one record.

Examples:

- 2080: First Machine War begins
- 2083: Shanghai falls
- 2089: Atlas founded
- 2102: ECHO born
- 2120: First Ghost Incident
- 2147: White Ghost Team founded

Output: ECHO Chronicle.

## Stage 3: Month 6, Character Universe

Goal: expand to 300 characters.

Distribution:

```text
CHASER: 50
Ghost: 50
Atlas: 50
Black Zone: 50
Dream Network: 50
Free characters: 50
```

At this point the character library should approach the scale of a major game IP.

## Stage 4: ECHO Factory

Goal: make the universe run as an agent project.

ECHO Factory has 8 agents:

- Lore Agent
- Character Agent
- Relationship Agent
- Faction Agent
- Technology Agent
- Story Agent
- Art Director Agent
- Consistency Agent

## Long-Term Shape

After one year, expected scale:

- Characters: 300+
- Organizations: 30+
- Cities: 50+
- Technologies: 200+
- Historical events: 1000+
- Manga chapters: 200+
- Fiction: 3,000,000+ Chinese characters or equivalent long-form prose

At this point ECHO is not just a comic. It is a continuously growing digital life-form project.

## Agent Character Future

Every major character can become a real agent.

Zero, Kane, Luna, Shion, and others should eventually have:

- Memory
- Relationships
- Growth records
- Conversation ability
- Canon-safe behavior constraints
- Personal timeline
- Art assets

This enables:

- Worldbuilding
- Comics
- Games
- AI character social experiences
- Digital personality universe
