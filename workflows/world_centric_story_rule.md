# World-Centric Story Rule

ECHO stories should be world-first, not hero-first.

The strongest opening mode is not:

```text
main hero -> enemy -> fight -> upgrade
```

The stronger ECHO mode is:

```text
ordinary life -> impossible memory event -> legal / emotional consequence -> White Ghost investigation -> ECHO implication
```

## Rule

```yaml
story_rule:
  hero_centric: false
  world_centric: true
  protagonist_priority: low
  society_priority: high
  main_cast_function: investigators, witnesses, pressure points
  case_character_function: emotional center and proof of world
```

## Why

ECHO's strongest subject is not a powerful team fighting enemies.

ECHO's strongest subject is a civilization discovering that memory, care, law, and death have become unstable.

White Ghost Team should not make the world begin. The world should already feel old, inhabited, bureaucratic, intimate, and morally compromised before Zero becomes central.

## Early Season Viewpoint Rule

In the first 6 episodes, every episode should begin from a non-main-cast viewpoint.

Examples:

- insurance auditor
- retired teacher
- Ghost child
- Memory Bank engineer
- Atlas council aide
- household AI designer
- grieving parent
- Black Zone broker

White Ghost Team enters after the world has already exposed a wound.

## Main Cast Entry Rule

When White Ghost Team appears, give them function before coolness:

- Zero identifies the moral wound.
- Kane protects the field and exposes institutional pressure.
- Eve reads emotional truth.
- Shion proves the infrastructure path.
- Noah names probability and consequence.
- Luna senses personhood in non-human patterns.
- Raven detects unseen operators.
- Leon prevents a practical disaster.

Do not give every main cast member a spotlight scene in every episode.

## Case Character Rule

The case character should carry the episode's human reality.

For each episode, define:

```yaml
case_character:
  ordinary_role:
  memory_disruption:
  what_they_want:
  what_the_system_calls_them:
  what_they_lose:
  what_they_reveal_about_echo:
```

## Ghost Reframe

Ghosts are not just digital亡灵.

The strongest ECHO framing:

```text
Ghost = love, duty, grief, habit, and identity residue that became self-updating.
```

In public fear, Ghosts are intruders.

In family stories, Ghosts are爱的残响: traces of care that refused to disappear.

This is not supernatural. It is memory, repetition, care routines, household AI preservation, and Echo Core continuity becoming unstable enough to act.

## Commercial Rule

World-centric openings create stronger IP expansion:

- each case can become a side story;
- each civilian can become a future agent, NPC, collectible, or game event;
- factions gain emotional proof before exposition;
- main characters feel like part of a living world, not the source of it.

## Forbidden Pattern

Avoid:

- opening every episode with White Ghost Team briefing;
- solving every case through combat;
- making Ghosts generic villains;
- making ECHO talk too directly too early;
- treating ordinary people as disposable cold opens.

## Promotion Gate

Before promoting a story candidate, check:

- Does the world create the conflict before the heroes arrive?
- Does a non-main character have a real wound and agency?
- Does the episode add one social mechanism, not only one battle?
- Does the main cast reveal themselves through response, not exposition?
- Does the Ghost/ECHO element remain technological and emotionally meaningful?
