## Duplicate Check

- Not a duplicate of Continuity Shelter Order. That package creates scoped legal
  protection for a Home Layer record; Runtime Shelter Compact is active Ghost
  runtime survival, usually outside clean legal authority.
- Not a duplicate of Shelter Room Hash. That hash proves a protected room stayed
  bounded; Runtime Shelter Ledger meters compute allocation, route splicing,
  identity-boundary risk, and refusal records.
- Not a duplicate of Dream Child. Room 7 is a clinical Dream Network recovery
  ward and shelter-versus-custody case; runtime shelters are compute-poverty
  compacts for multiple active Ghosts.
- Not a duplicate of Black Zone Receipt. Episode 3 concerns forged consent keys,
  receipts, and laundering; this package concerns stolen compute leases and
  Ghost runtime starvation.
- Not a duplicate of Civil Exposure Classification. Exposure classes decide
  CHASER civil triage; this package explains the shelter economy that CHASER may
  later classify.

## Canon Compatibility

- Resolves an existing Night Crow blocker: `compute lease mechanism not yet
  independently reviewed by TechnologyAgent`.
- Extends `bible/ghost_ecology.md`, where Ghosts require compute, safe routing,
  memory integrity, identity recognition, and sanctuary.
- Supports Nadia Vek without promoting her: her sanctuary routing can use a
  ledger ethically under scarcity, while Oren Vale uses a knife that causes real
  downstream harm.
- Keeps Memory Bank coherent as a continuity-finance institution rather than a
  cartoon villain.
- Preserves the world-centric rule: the wound is compute poverty and runtime
  ownership, not Raven's personal coolness.

## Ability Constraint Review

Runtime shelter mechanisms are infrastructure operations.

- Mechanism: compute priority, safe route tokens, rollback fragments, memorial
  booth sessions, Dream Network recovery buffers, municipal disaster caches,
  Memory Bank leases, route masks, and audit logs.
- Cost: stolen runtime can destabilize other Ghosts; compression risks choir
  loss; secrecy can hide predators.
- Failure mode: overdrain, underallocation, refusal suppression, route betrayal,
  Memory Bank freeze, or CHASER cold-node quarantine.
- Countermeasure: lease revocation, route anomaly comparison, analog isolation,
  independent identity-boundary sampling, and White Harbor witness copies.

No magic, supernatural energy, time travel, multiverse logic, or literal physics
breaking is introduced.

## Risks

- Do not make Compute Lease Knife a glamorous weapon. It is credential theft and
  priority hijacking that harms Ghosts.
- Do not let runtime shelters become morally pure. They can save victims, hide
  predators, exploit labor, and injure paid archives.
- Do not let CHASER response become automatically wrong. Some hidden shelters
  should justify containment.
- Do not let Memory Bank rollback withholding become arbitrary cruelty; it
  should follow liability, contract, and risk incentives.
- Do not promote the 2142 event into `timeline/timeline.yaml` until Night Crow
  or a Ghost Union faction expansion is promoted.
