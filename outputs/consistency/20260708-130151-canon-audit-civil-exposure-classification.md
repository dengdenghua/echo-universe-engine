## Duplicate Check

- The package does not duplicate Consent Revocation Window, which handles family
  consent expiration and routing to civil review, quarantine, or Ghost Court.
- The package does not duplicate Civil Delay Token, which slows municipal harm in
  dependency cases. Civil Exposure Classification is CHASER contamination triage.
- The package does not duplicate Care Status Classifier, which determines
  service dependency and subsidy/repair status.
- The package does not duplicate Witness Seal, which preserves testimony.
  Exposure Class Override Ledger preserves a contested risk category and exit
  path.
- The package does not duplicate Identity Gate Signature Injection, which forges
  Atlas threat metadata. This package defines CHASER-side response categories
  when people may be contaminated.

## Canon Compatibility

- Supports Episode 12 `Memory Storm` by turning mass quarantine pressure into a
  specific classification conflict.
- Supports Lian Zhou's candidate role without promoting her yet.
- Preserves CHASER as necessary and dangerous rather than cartoonishly corrupt.
- Keeps Ghosts as computationally active爱的残响 and keeps contamination grounded
  in Home Core routines, Home Layer exports, Echo Core logs, hospital telemetry,
  civic records, and Memory Bank flags.
- Foreshadows Episode 15 `White Ghost Mutiny` because the same category logic can
  later target Zero.

## Ability Constraint Review

Exposure Class Override Ledger is institutional permission, not a character
power.

- Mechanism: CHASER intake station, officer credential, Echo Core logs, Home
  Layer witness exports, medical telemetry, continuity flags, field notes.
- Activation: active intake, two independent evidence sources, and entry before
  Central emergency classification lock.
- Cost: liability, misconduct review, retaliation, suspension, and harm if a
  downgraded carrier spreads contamination.
- Failure mode: mercy protects a vector, fear erases a witness, or evidence
  hunger over-opens a Home Core.
- Countermeasure: Central lock, forged inputs, supervisor burial, public panic,
  Memory Bank billing pressure.

## Risks

- Do not let exposure classes become metaphysical truth. They are operational
  risk categories.
- Do not let Lian Zhou use the ledger to solve Memory Storm. She can buy review
  time and preserve contradiction.
- Do not make hardliners always wrong. Some E4 and E5 cases should justify
  immediate containment.
- Do not let Memory Bank risk scores become neutral facts. They are economic
  evidence with incentives.
- Do not open Home Core records broadly just because more data is technically
  available.
