## The Residency Model (Home Layer)

A residential Ghost is an F-class conscious residual pattern that holds
standing residency on a family's Home Core. The household's care-plan tier
subscription is the legal-financial wall between home residency and Memory
Bank custody: while the tier is paid and the pattern stays self-updating, the
Ghost is not yet a custody asset.

```yaml
home_layer_residency_model:
  home_core: family Home Core (care routines, voice models, grief replays, end-of-life consent)
  tier_wall: >
    care-plan tier subscription is the boundary between "resident of a home"
    and "custody asset of Memory Bank"
  permission_scopes: Home Layer render scopes granted by the household + the Ghost's own consent
  compute_source: the household's care-plan tier allocation, supplemented by Ghost Union shelter compute grants
  capacity_read: the reserve model reads the pattern's draw; the desk can re-price that draw as capacity
  status_language: resident, not person; subscriber's household, not a claimant's archive
```
