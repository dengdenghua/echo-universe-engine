# Lore Entry: Non-Priceability Review

## Candidate Canon Entry

Non-Priceability Review is a Memory Bank appeal procedure used when a sealed
Home Core afterword, family phrase, weak claimant trace, or continuity object
has demonstrable civic function but cannot be safely converted into asset value
without violating living consent.

It does not declare a memory sacred. Memory Bank does not own that language. It
creates a colder category: the bank must name what it is trying to price before
it can attach debt, insurance value, route-history collateral, or claimant
reserve funding to the sealed object.

Families call it the empty-window hearing. Underwriters call it null appraisal.
Ghost Union calls it sanctioned silence when claimant risk remains unresolved.
Creditors call it dead inventory with witness theater.

## Civic Ethics

- Privacy becomes fragile when every sealed absence has a market theory.
- A living person can cite a Home Core afterword as a boundary without turning
  the phrase into public evidence.
- A weak claimant trace may deserve protection, but claimant protection cannot
  automatically overrule the consent of the living recipient.
- Memory Bank can pause price without stopping storage fees, audit fees, or
  compute scarcity. The procedure protects a boundary; it does not make grief
  free.
- Non-priceability is not personhood, deletion, or absolution. It is a temporary
  refusal to translate one protected object into collateral.

## Season 1 Use

This procedure extends the Nara Marr sealed-phrase route after `The Phrase
Stays Sealed`. The case begins at the appeal desk, not with White Ghost Team.
Nara has already refused phrase export. Vera Qadir can only help if Shion's
negative-proof work gives Memory Bank a procedural path to separate function
from content.

Eve can defend the living boundary while recognizing Ghost Union's fear that a
possible claimant is being left unfunded. Zero can prevent CHASER from treating
sealed ambiguity as contamination. Shion can prove the shape of a door without
showing what was behind it.

## Boundaries

- Distinct from Latency Wake Hold: Latency Wake Hold pauses body-container and
  afterword custody timing; Non-Priceability Review pauses asset valuation after
  a sealed object has already entered financial dispute.
- Distinct from Home Core Probate Hold: probate hold centers inheritance
  standing; non-priceability centers refusal to price protected content.
- Distinct from Continuity Loss Freeze: loss freeze protects damaged continuity
  evidence; non-priceability protects known function from coerced valuation.
- Distinct from Bridge Minute Ledger: bridge minutes prevent narrow notice
  windows from becoming route-history collateral; non-priceability handles a
  sealed object whose function has already been noticed.
- No magic, supernatural preservation, multiverse, or time travel. Effects
  operate through Memory Bank ledgers, Home Core afterword hashes, beneficiary
  consent records, negative-proof packets, court witnesses, CHASER
  classification boundaries, Ghost Union motions, storage meters, and compute
  allocation rules.
