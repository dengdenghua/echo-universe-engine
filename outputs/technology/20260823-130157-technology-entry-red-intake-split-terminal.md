# Technology Entry: Red Intake Split Terminal

## Candidate Canon Entry

The Red Intake Split Terminal is the CHASER civil-intake workstation used to
open, narrow, appeal, and expire a Red Intake Split.

It is not an ability and not an artificial judge. It is a constrained interface
that links sealed witness statements, Home Core disclosure scopes, access
ledgers, motor-habit packets, exposure class records, guardian permissions,
employment credentials, and CHASER specialist queues.

Its dramatic value is that it makes institutional harm visible as interface
state: one screen protects a witness's statement while the adjacent panel pauses
ordinary life.

## System Shape

```yaml
red_intake_split_terminal:
  operator: "CHASER civil contamination intake registrar"
  minimum_inputs:
    - contamination trigger id

  protected_outputs:
    - witness-side statement hash
    - consent scope receipt
    - analog appeal notice code
    - registrar liability signature
  restricted_outputs:
    - temporary permission pause
    - travel gate slowdown
    - guardian-action review flag
    - work credential hold when evidence supports it
```

## What It Can Do

- Separate a witness's testimony from the permission restrictions attached to
  the same incident.
- Enforce a visible seventy-two-hour clock.
- Require a named anomaly class before restriction starts.
- Record whether CHASER requested a narrow packet or a broad Home Layer export.
- Print an analog appeal notice that survives terminal lockout.
- Attach a registrar's name to both protection and harm.

## What It Cannot Do

- Certify that a Ghost is present.
- Prove legal continuity or personhood.
- Read private memories without scoped consent or legal order.
- Override CHASER Central emergency command lock.
- Release an active vector after confirmed propagation.
- Prevent Memory Bank or Atlas systems from applying downstream pressure once
  a restriction flag exists.

## Failure Modes

- Scope creep: a motor-habit packet becomes a full Home Layer disclosure
  request because broad data is easier to defend.
- Timer fraud: the seventy-two-hour clock restarts under a new incident number.
- Interface bias: red visual language makes a protected witness look guilty to
  every later reviewer.
- Ledger spillover: a work credential hold travels farther than the original
  case file.
- Appeal dead end: the printed notice names a right but routes the witness to an
  overloaded desk.

## Countermeasures

- Store witness-side and restriction-side hashes separately.
- Require a supervisor reason for any disclosure expansion.
- Log timer resets as renewals, not new splits.
- Mark Memory Bank risk flags as economic claims, not contamination evidence.
- Preserve the analog appeal code even when the witness's travel and work access
  are slowed.
- Let Shion-style packet review clear or narrow the split without opening the
  household's full Home Layer.

## Story Use

- Inez can perform the procedure, but the terminal keeps her from pretending it
  is harmless.
- Zero can read the mismatch between a frightened witness and the red state on
  the screen.
- Eve can challenge consent scope.
- Shion can argue that the technical packet is enough.
- Lian Zhou can require an exposure-class rationale before escalation.
- Kane can see why field teams prefer fast restriction after visible risk.

## Consistency Notes

- Distinct from Echo Core abilities. This is civic infrastructure and
  permissions logic, not neural power.
- Distinct from Exposure Class Override Ledger. The terminal may call that
  ledger, but the split's purpose is rights and permission separation.
- Distinct from Witness Seal. The terminal includes sealed testimony but also
  creates temporary permission harm.
- It supports early Season 1 aftermath without revealing Project E-01, Omega,
  Mother, God Fragments, or ninth upload material.
