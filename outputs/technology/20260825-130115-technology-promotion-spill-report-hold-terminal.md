## Technology Decision

Promote Spill Report Hold Terminal as a limited Dream Network Civic Claims
tool. It is now reusable Season 1 infrastructure for public-route refund and
harm complaints.

## Promoted Function

The terminal can:

- pause automatic refund closure before payout purges route telemetry;
- preserve route-state hash, consent-boundary snapshot, affective spill hash,
  rendered-phrase fingerprint, and optional wake-anchor reference;
- record Home Core or Home Layer involvement as hash-only;
- create a narrow packet for consent review, Dream Network safety review,
  Memory Bank archive dispute, or CHASER low-threat notice.

## Canon Limits

The terminal cannot:

- enter dreams;
- read minds;
- prove Ghost personhood;
- identify a child from a phrase or lullaby fingerprint;
- override Memory Bank ownership claims;
- make CHASER containment decisions;
- stabilize a responsive pattern after compute is withdrawn.
