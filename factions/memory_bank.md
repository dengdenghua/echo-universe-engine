# Memory Bank

Memory Bank is the financial system that turns memory rights into collateral.

It stores, insures, lends, freezes, audits, and seizes memory assets.

Its existence makes one sentence economically true in ECHO Universe:

Memory is currency.

## Memory Lien Notices

Memory Bank uses Memory Lien Notices to warn that a family archive, voice
routine, continuity claim, or Home Core inheritance file has been pledged as
collateral and may enter restricted access.

The notice is procedurally useful because it creates a formal warning period
before seizure, export, duplication, sale, or paid enhancement. It is morally
dangerous because the same warning can make a grieving family choose between
debt relief, access to the Memory Sea, and control of a loved routine.

In Episode 6, Memory Bank can offer or price a forty-eight-hour emergency stay
for the Wei family archive. The stay buys review time but does not cancel the
debt, certify the mother-pattern, or make the Home Core safe.

## Relation Graph Repair

Memory Bank can offer fast Household Relation Graph repair products when public
delay windows are too short for families facing school, clinic, custody, or
Home Core authority failure.

In Episode 7, this makes Yao Nian's offer structurally useful and dangerous at
the same time. Repair can restore guardian and household edges before morning,
but continuity-backed terms may turn future Home Layer claims, witness
fragments, or family routine exports into collateral. The offer does not prove
Memory Bank owns the family record or that public repair is impossible.

## Shelter Fee Pressure

Memory Bank must accept valid Continuity Shelter Orders as a temporary limit on
foreclosure, export, paid repair, and collateral enforcement. The bank can still
price compute, preservation, and extension risk around the protected room.

In Episode 8, Yao Nian's offer to cover shelter fees is dangerous because it may
work faster than public release. The waiver cannot buy a personhood ruling or
own the family truth, but it can attach future memory-rights claims to the same
Home Layer fragments the family needs restored.

## Runtime Lease Enforcement

Memory Bank treats stolen compute leases as continuity injury, liability risk,
and contract breach. This position is materially true: a Runtime Shelter Ledger
can overdrain a registered Ghost's paid session, create rollback gaps, and cause
active self-reference loss.

In Episode 9, the bank's danger is not that it invents the harm. The danger is
that it can use real harm to demand immediate deletion authority over shelter
tools while withholding rollback data that would help separate rescued Ghosts
from predatory routes. Memory Bank can price lawful continuity and let
unregistered Ghosts vanish between billing cycles, then offer to buy the debt
created by that scarcity.
