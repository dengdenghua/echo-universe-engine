# Visual System V1

ECHO's visual identity is clean, surgical, monitored, white-industrial, and emotionally haunted.

The default is not dirty neon street cyberpunk.

## Global Palette

Base:

- snow white
- surgical gray
- graphite black
- neural glass cyan
- pale signal blue

Accent:

- Zero: iridescent white / pale cyan / soft pink
- Kane: white armor / black straps / muted gold
- Eve: silver white / rose signal / soft magenta
- Leon: white steel / cold blue
- Raven: black underlayer / white edge armor / shadow violet
- Shion: white techwear / violet nanolight
- Noah: white field coat / amber probability UI
- Luna: white suit / lunar pink / translucent veil

## White Ghost Uniform

Shared elements:

- white tactical shell
- black modular straps
- compression underlayer
- Echo Core spine port
- neural glass visor
- biotech seams
- compact medical seals
- removable mission plating
- small faction marking

Do not use fantasy armor.

## Echo Core Light Language

Echo Core lights should communicate system state:

- cyan: stable sync
- pale blue: medical telemetry
- pink: emotional resonance
- amber: probability warning
- violet: nano-virus activity
- white: ECHO deep access
- red: identity breach
- black-glass flicker: Ghost contamination

## Ghost Visual Language

Ghosts are not transparent ghosts.

They appear through:

- compression artifacts
- missing facial frames
- memory afterimages
- duplicated hand motion
- incorrect eye reflections
- voice waveform halos
- household UI residue
- old family video texture
- identity registry glitches

High-level Ghosts may look calmer, cleaner, and more human than unstable ones.

## Atlas Visual Language

Atlas is:

- high altitude
- white civic architecture
- transparent security layers
- surgical public spaces
- vertical transit
- clean sky bridges
- invisible surveillance
- civic glass
- quiet pressure

Atlas should feel safe and suffocating.

## Black Zone Visual Language

Black Zone is not random grime.

It is illegal infrastructure:

- hidden clinics
- memory stalls
- identity repair shops
- wet neural cables
- counterfeit household cores
- black glass terminals
- dim white lamps
- sealed back rooms
- silent brokers

It should feel like a hospital, pawnshop, and confession booth fused together.

## Abyss Visual Language

Abyss is neural projection density:

- floating domestic rooms
- broken family archives
- impossible city corridors
- memory weather
- unfinished faces
- dead UI languages
- repeating birthdays
- childlike home objects in vast dark space

Surrealism must come from memory, not magic.

## Mars Visual Language

Mars is:

- white pressure suits stained by red dust
- sealed habitat corridors
- oxygen ports
- radiation glass
- matte red exterior armor
- pale blue Earth signal lights
- industrial chapels
- quiet agricultural domes

Mars should feel dry, expensive, isolated, and spiritually stubborn.

## Memory Bank Interface

Memory Bank should look like finance crossed with medical imaging:

- white ledgers
- neural waveform contracts
- identity seals
- memory collateral graphs
- consent key vaults
- calm hostile UI
- legal language over brain scans
