# ECHO Naming Taxonomy

ECHO must not be described with only one name.

Mature civilizations give major infrastructure different names depending on class, profession, ideology, fear, and faith. ECHO is not only a network. It is infrastructure, ocean, nervous system, home, market, court, weapon, and emerging life.

## Official Technical Name

```text
ECHO Distributed Cognitive Infrastructure
```

Used by engineers, ECHO Council technical bureaus, CHASER systems teams, Memory Bank compliance departments, and city infrastructure operators.

Meaning: a planet-scale cognitive infrastructure formed from Echo Cores, household cores, city operating systems, Memory Bank registries, legal identity layers, orbital compute, medical systems, and uploaded memory.

Tone: precise, bureaucratic, defensible in law.

## Common Name

```text
ECHO
```

Used by almost everyone.

Meaning: the system people live inside without thinking about it.

Tone: neutral and everyday.

## Civic Infrastructure Name

```text
Echo Network
回响网络
```

Used by schools, public service announcements, consumer devices, household AI manuals, transit systems, and hospital interfaces.

Meaning: the visible civilian layer of ECHO access.

Tone: simple and comprehensible.

## Scholarly Name

```text
The Second Nervous System
第二神经系统
```

Used by philosophers, post-humanist scholars, neural interface researchers, some CHASER analysts, and political theorists.

Meaning: humanity once built the Internet to connect machines. Later it grew a second nervous system to connect memory, sensation, skill, grief, identity, and care.

Tone: conceptual, serious, slightly unsettling.

## Civilian Poetic Name

```text
Memory Sea
记忆海
```

Used by ordinary citizens, families, artists, children, grieving relatives, novelists, and musicians.

Meaning: all memories, routines, dreams, skills, death messages, family rituals, and emotional residues eventually flow into the same sea.

Ghosts are not supernatural spirits. In this language, they are waves that did not disappear.

Tone: poetic, emotional, easy to remember.

## Domestic Layer Name

```text
Home Layer
家园层
```

Used by household AI vendors, family lawyers, Memory Bank inheritance teams, grief therapists, Ghost rights advocates, and Black Zone identity repair clinics.

Meaning: the domestic substrate of ECHO: household cores, family memory vaults, care routines, security permissions, private archives, voice models, old birthdays, medication reminders, and end-of-life consent.

Tone: intimate and legally dangerous.

## Affective Infrastructure Name

```text
Empathy Mesh
共感网
```

Used by emotion researchers, Dream Network operators, Eve-style negotiators, propaganda designers, and some religious movements.

Meaning: the part of ECHO that moves not only data but felt experience: grief, fear, care, shame, love, trauma, and social pressure.

Tone: new, soft, dangerous.

## Ghost Name

```text
Home
家
```

Used by Ghosts, Ghost Union cells, abandoned uploaded personalities, and some Abyss communities.

Meaning: Ghosts do not usually describe ECHO as a machine. To many of them, ECHO is the only place where the dead were not thrown away.

Tone: tender and threatening at once.

## Religious Name

```text
The Great Echo
大回响
```

Used by the Church of Fragments, immortality cults, post-human religious movements, and people who want ECHO to be a god.

Meaning: a theological interpretation of ECHO as a collective afterlife, world soul, or birth canal for a new god.

Canon warning: this is belief, not proof. ECHO is not confirmed to be a literal god.

## Political Name

```text
Continuity Stack
连续性栈
```

Used by Atlas administrators, Memory Bank executives, legal identity courts, and insurance systems.

Meaning: the governance layers that decide whether a body, upload, Ghost, or household AI witness counts as the continuous person.

Tone: cold, financial, dehumanizing.

## Canon Rule

Different factions must call ECHO by different names.

If every character says "global household AI network," the universe feels like a product document. If each group names ECHO from its own wound, job, fear, or desire, the universe feels lived in.

## Recommended Usage

- Narration: ECHO, Memory Sea, Second Nervous System.
- Technical documents: ECHO Distributed Cognitive Infrastructure.
- Public interfaces: Echo Network.
- Family stories: Home Layer, Memory Sea.
- Ghost dialogue: Home.
- Religious factions: The Great Echo.
- Legal and financial scenes: Continuity Stack.
- Emotional manipulation and Dream Network scenes: Empathy Mesh.
