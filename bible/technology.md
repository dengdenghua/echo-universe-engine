# Technology

## Echo Core

Every person is born with or implanted with an Echo Core seated between the spine and brainstem. The Echo Core connects a person to ECHO.

Capabilities:

- Memory upload
- Skill download
- Collective intelligence access
- Digital continuity services
- Neural interface traversal

Constraints:

- Echo Core abilities require signal, compatible neural structure, and biological load tolerance.
- Abilities can damage memory, identity continuity, and physical tissue.
- No Echo Core ability is supernatural.

## Skill Download

Skill Download transfers procedural memory patterns into a body. It is not mastery without cost. Bodies still need tolerance, reflex calibration, and emotional stability.

## Memory Upload

Memory Upload records memory streams into ECHO. Uploads can preserve continuity, but continuity is disputed when multiple copies diverge.
