ECHO UNIVERSE · CONTENT API

读取一个持续生长的世界

ECHO Universe 把角色、派系、正典状态与世界事件以只读 JSON 暴露出来。下面每个接口都来自运行中的服务，不是规划稿。

—公开只读接口 —角色档案 无需密钥公开层调用

01 · QUICK START

第一次调用

公开只读接口不需要任何凭据。基址即部署域名，响应一律为 UTF-8 JSON。

curl
curl -s https://universe.echo-age.com/api/canon/status

状态字段区分 canon（已通过连续性审核）与 candidate（候选，可能在审核后调整）。请不要把 candidate 内容当作最终设定缓存。

02 · IDENTITY

三层身份

接口按可见性分三层。公开层之外的调用在生产环境一律需要凭据，未配置凭据时服务会直接返回 503 而不是降级放行。

PUBLIC

公开只读

世界观内容、正典状态、经济商品与身份档位。无需凭据。

无
USER

用户层

个人绑定、余额与宇宙信息流。需用户 JWT，且只能访问自己的数据。

Authorization: Bearer <jwt>
ADMIN

管理层

内容写入、Agent 执行、资产生成与治理晋升。仅限运营。

X-Echo-Api-Key: <key>

跨用户访问会被拒绝：即使持有合法 JWT，请求他人 user_id 的数据也会返回 403。

05 · CONSTRAINTS

当前的真实限制

这些是接口现在的状态，不是将来的承诺。先看清楚再决定怎么接。

  • 没有 CORS 响应头 浏览器跨源请求会被拦截。第三方前端需自建服务端代理，或等待正式开放。
  • 没有速率限制 公开层目前不限流，也因此不承诺可用性。请自行加缓存与退避，不要把它当高可用数据源。
  • 字段未冻结 接口未版本化，字段可能随内容层演进调整。请容错处理未知字段。
  • 暂无 SDK 没有官方客户端库。直接用 HTTP 即可，响应是普通 JSON。
  • 候选内容会变 status 为 candidate 的条目尚未通过连续性审核，展示时应保留候选标注。
