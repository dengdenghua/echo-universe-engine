
白港不是被闹钟叫醒的。

它在一层一层的白光里苏醒。

清晨七点十三分，住宅塔群的睡眠遮光板按照家园核心的建议缓慢升起。窗外的天空被海雾洗成冷淡的银灰色，城市外壳上的除湿膜开始工作，垂直轨道边缘的安全灯逐级点亮。每一户家园核心都在同一时间完成自己的小型晨祷：降低早餐温度，调整儿童制服的领口硬度，提醒老人服药，过滤昨夜梦境里不适合上传到家园记忆库的片段。

没有人把这称为祈祷。

白港人不向 ECHO 下跪。他们只是醒来，刷牙，抱怨租金，接受营养方案，确认通勤路线，然后把昨天没力气记住的东西交给家园核心保存。旧时代的人把互联网装进口袋。回响纪元的人把家装进脊柱。

林乔也一样。

她三十二岁，白港联合保险的初级审计员，负责核对意外理赔里那些不够像意外的细节。她没有外科执照，没有军方履历，没有 Ghost 接触史。她的 Echo Core 今年扫描过两次，结果都很普通：稳定同步，低风险记忆谱，无继承性人格债务。

普通在白港是一种资格。

七点四十一分，林乔走进白港轨道 L-7 线，左手拿着一杯合成咖啡，右眼角的神经界面悬着一条来自父亲的未读消息。

“今晚回家吃饭吗？”

她看了一眼，没有回复。

车厢很干净。白色扶手，浅灰座椅，透明广告层上滚动着 Memory Bank 的宣传语：

死并不意味着告别。请为你的家人保留一个完整的你。

林乔移开视线。她每天都会看到这句广告，白港每个人都会看到。它不再像承诺，更像水费单和天气预报之间的一部分。

七点四十四分，列车折叠了。

不是爆炸。

爆炸属于旧城市和便宜故事。L-7 的安全脊柱误读了压力差，前三节车厢被锁死，后两节车厢按照系统仍然认为“安全”的速度压了上来。白色复合玻璃碎成粉末，座椅像闭合的夹具一样变形。灯没有熄灭。应急照明甚至更亮了一点，亮到每个乘客都能清楚看见城市是如何精确地失败。

林乔醒来的时候，脸上有别人的血。

她半边身体被断裂扶手压住，左手的咖啡不见了。耳边充满系统广播的安抚音：

请保持平静。公共医疗响应已启动。请保持平静。

有人在哭。有人在咳。有人一遍遍叫同一个名字。

林乔想动，却先听见了一个孩子的呼吸声。

那声音太轻，像被一层湿布盖住。她转过头，看见一个九岁左右的男孩被维护板卡在座椅下方，腹部以下全是阴影。他母亲趴在旁边，手指抠着变形金属，指甲已经裂开。

一架医疗无人机悬在孩子上方，柔和的蓝光扫过伤口，然后用平静得近乎残忍的声音重复：

“进入角度不足。请等待认证救援。”

男孩的母亲尖叫起来。

林乔不知道自己是什么时候爬过去的。

她只记得手很稳。

那不是她熟悉的稳定。审计员的稳定来自表格、证据链、重复核对。现在她的稳定来自更深处，来自一套她从未学过的身体习惯：先看瞳孔，再看呼吸，再判断出血位置。恐惧还在，但恐惧被推到了一堵墙后面。

“不要拉那块板。”她说。

男孩的母亲愣住。

林乔的声音低了半度，语速也变了。

“你拉开，他会死。”

她撕下自己的袖口，把布料卷成临时压迫带。她的手指按在孩子肋骨下方某个她不该知道的位置，另一只手向上抓住医疗无人机的稳定环。

“释放血管封闭剂。”

“权限不足。”无人机回答。

林乔没有犹豫。她拇指卡进无人机底部的安全槽，向左旋了十五度，再向下压。那动作太准确，像做过几千次。卡匣落入她掌心。

她听见旁边有人喊：“你是医生吗？”

她没有回答。

她知道该怎么回答，但那个答案不属于她。

三分钟后，男孩活了下来。

四分钟后，CHASER 的第一道黑色封锁线落在车厢门口。

七分钟后，林乔坐在白色担架旁，低头看着自己的双手，终于开始发抖。

她哭不是因为害怕。

她哭是因为她不知道怎么停止当一个外科医生。
