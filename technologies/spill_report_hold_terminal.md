# Spill Report Hold Terminal

The Spill Report Hold Terminal is a Dream Network Civic Claims tool that pauses
automatic refund closure for a licensed public route. It preserves a scoped
post-incident telemetry packet before payout purges the route record.

It does not enter dreams, read minds, identify a child, prove Ghost personhood,
override Memory Bank ownership, or make CHASER containment decisions. Its value
is procedural: it keeps evidence alive long enough for consent, safety, and
archive-review specialists to decide what can be reviewed without exposing a
family's private Home Layer.

## Preserved Scope

```yaml
spill_report_hold:
  preserved_material:
    - route_state_hash
    - consent_boundary_snapshot
    - affective_spill_hash
    - rendered_phrase_fingerprint
    - wake_anchor_reference_optional
    - home_core_texture_reference_hash_only
  prohibited_exports:
    - full_home_layer_memory
    - raw_child_voice_model
    - unrelated_family_archive
    - live_session_body_state_without_scope
  hold_window:
    default_hours: 48
    emergency_extension_hours: 24
    purge_on_release: true
```

## Canon Limits

- A hold can delay evidence deletion; it cannot stabilize a responsive pattern
  if compute is withdrawn.
- A lullaby or phrase fingerprint can justify comparison; it cannot identify
  the child or settle whether the response is a Ghost.
- A Home Core or Home Layer reference remains hash-only unless a separate
  consent scope, court order, or specialist review authorizes deeper access.
- CHASER receives route-level low-threat notice only unless later evidence
  earns escalation.

## Story Use

The terminal makes Episode 5's civic wound visible: a family can need the money
from a refund and still need the room not to disappear. White Ghost Team enters
through a held packet, not through a combat alarm or supernatural signal.
