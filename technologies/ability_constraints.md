# Ability Constraints

Every ECHO ability must be technological, limited, and costly.

Abilities are not superpowers in the magical sense. They are dangerous uses of Echo Core interfaces, predictive systems, biotech, city infrastructure, memory systems, nanotech, and distributed computation.

## Zero: Neural Sync

Mechanism:

Deep Echo Core synchronization with another mind or memory stream.

Can:

- read memory fragments
- align with another neural rhythm
- copy limited procedural skills
- detect identity discontinuity
- hear ECHO resonance

Cannot:

- read every thought perfectly
- resurrect the dead
- copy a whole person safely
- bypass all consent keys without risk

Cost:

- identity bleed
- memory contamination
- ECHO vessel behavior
- loss of self-boundary

Countermeasure:

- Memory Anchor
- neural firewall
- fragmented memory decoys
- Ghost Court consent lock

## Kane: Combat Download

Mechanism:

Temporary procedural memory injection into motor and tactical systems.

Can:

- learn weapon handling quickly
- copy combat drills
- adapt to battlefield tools
- execute unfamiliar techniques

Cannot:

- exceed body tolerance
- gain emotional mastery
- avoid trauma residue
- permanently master everything

Cost:

- tremor
- fatigue
- borrowed fear
- reflex mismatch
- procedural addiction

Countermeasure:

- unpredictable civilian environment
- emotional overload
- motor disruption
- false procedural pattern

## Eve: Emotion Hack

Mechanism:

Echo Core-mediated affective modeling and neural-emotional signal influence.

Can:

- calm panic
- amplify fear
- detect emotional lies
- interrupt mob contagion
- negotiate with unstable Ghosts

Cannot:

- create true love
- permanently rewrite personality
- control people with no signal route
- overcome strong memory anchors easily

Cost:

- emotional feedback
- empathy fatigue
- self-contamination
- moral guilt

Countermeasure:

- emotional noise
- anchor memories
- affective shielding
- distributed group emotion

## Leon: Time Echo

Mechanism:

High-speed predictive simulation using sensor data, combat pattern libraries, and probability modeling.

Can:

- see likely action paths up to about three seconds ahead
- predict attacks
- identify probable escape windows
- fight with impossible precision

Cannot:

- travel through time
- see fixed destiny
- predict chaotic unknown variables
- avoid biological cost

Cost:

- neural burn
- shortened healthy lifespan under deep use
- migraine
- decision paralysis

Countermeasure:

- randomness
- hidden actors
- sensor denial
- emotional misdirection

## Raven: Shadow Link

Mechanism:

Low-signal routing through cameras, dark architecture, blind spots, sensor noise, and local mesh gaps.

Can:

- move through surveillance dead zones
- jump data presence across dark network nodes
- mask approach
- exploit city blind spots

Cannot:

- teleport
- pass through walls
- operate in fully mapped clean light
- ignore physical distance

Cost:

- isolation from team telemetry
- navigation risk
- dependence on environmental shadow
- sensor backlash

Countermeasure:

- flood lighting
- redundant sensors
- analog barriers
- clean-room architecture

## Shion: Virus Queen

Mechanism:

Programmable nano-virus and swarm command through Echo Core signal choreography.

Can:

- infiltrate devices
- disable locks
- mark targets
- repair or damage micro-systems
- attack forged inheritance keys

Cannot:

- create life from nothing
- instantly consume cities
- bypass all air filtration
- control sealed analog systems

Cost:

- swarm drift
- immune reaction
- traceability
- emotional detachment

Countermeasure:

- sterile fields
- analog isolation
- swarm traps
- immune nanofilters

## Noah: Probability Engine

Mechanism:

Predictive allocation and micro-intervention across resources, timing, social behavior, and tactical options.

Can:

- raise event likelihood
- optimize routes
- find low-risk plans
- expose statistical weak points

Cannot:

- guarantee outcomes
- control consequence scale
- violate physics
- know unknown variables

Cost:

- displaced risk
- guilt from unseen consequences
- overfitting
- social detachment

Countermeasure:

- chaotic inputs
- hidden preferences
- adversarial randomness
- moral tradeoffs

## Luna: Dream Dive

Mechanism:

Neural traversal through Dream Network, memory residue, therapy environments, and Echo Core projection interfaces.

Can:

- enter shared inner worlds
- recover emotional evidence
- communicate with Ghosts
- navigate symbolic memory spaces

Cannot:

- enter supernatural dreams
- read all secrets
- safely stay indefinitely
- prove memory truth alone

Cost:

- self-loss
- Ghost attachment
- false memory infection
- emotional drowning

Countermeasure:

- projection locks
- memory labyrinths
- consent denial
- hostile therapy architecture

## Team Rule

Abilities should solve immediate tactical problems while creating deeper identity, memory, or relationship problems.
