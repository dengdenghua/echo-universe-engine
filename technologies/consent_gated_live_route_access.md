# Consent-Gated Live Route Access

Consent-Gated Live Route Access is the narrow civic-to-clinical packet that
allows a held Dream Network public-route claim to request supervised contact
with a hospital-attached live room.

It exists because a refund can pay a family while also deleting the only route
telemetry that shows the Memory Sea answered through the wrong channel. The
packet lets the money move while the record survives, but it does not turn
grief into broad permission.

## Canon Scope

For Season 1 Episode 5, the packet bridges Dream Network Civic Claims, the Spill
Report Hold Terminal, and Room 7. It is not a general Dream Dive license, not a
personhood ruling, and not a White Ghost Team override.

```yaml
consent_gated_live_route_access:
  episode_scope: "Season 1 Episode 5 / Dream Child"
  initiating_record:
    - spill_report_hold_id
    - refund_non_erasure_receipt
    - route_state_hash
    - consent_boundary_snapshot
    - affective_spill_hash
    - rendered_phrase_fingerprint_if_available
  required_authorities:
    family_scope_holder: required
    claims_witness: required
    consent_reviewer: required
    packet_validator: required
    clinical_supervisor: required
  allowed_modes:
    - observation_only_neural_interface
    - low_bandwidth_timing_ping
    - phrase_challenge_without_playback_export
    - analog_exit_phrase_test
  prohibited_material:
    - full_home_layer_export
    - raw_child_voice_model
    - unrelated_family_archive
    - live_pediatric_patient_link
    - identity_certification_flag
    - autonomous_white_ghost_entry
  first_contact_cap_minutes: 12
```

## Operating Rule

The access stays valid only while all required authorities remain in scope. If
Leina Elian or another family scope holder revokes consent, the room suspends
even if the packet is technically complete. If Memory Bank demands raw phrase
playback, if CHASER escalates beyond route-level notice without a new threshold,
or if the room links to a live pediatric patient, the packet closes or moves to
a separate review surface.

## Limits

- It can preserve and route a minimum packet; it cannot prove the response is a
  child, Ghost, malware, or licensed archive texture.
- It can support supervised Room 7 observation; it cannot authorize unsupervised
  Dream Dive or clinical custody.
- It can carry Home Core and Home Layer references as hashes; it cannot export a
  family's private Home Layer.
- It can give Luna a bounded witness role; it cannot make her the identity or
  rescue authority.

## Story Use

The technology keeps Episode 5 grounded in institutions: claims counters,
refund receipts, ward supervision, route notices, consent forms, and hash-only
memory evidence. It makes Leina's "Stop" an enforceable command rather than a
plea the system can ignore.
