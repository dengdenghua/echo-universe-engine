# Echo Core

Echo Core is the biological-cybernetic interface that links human neural systems
to ECHO.

## Known Abilities

- Neural Sync
- Combat Download
- Emotion Hack
- Time Echo predictive simulation
- Shadow Link
- Virus Queen nano-swarm command
- Probability Engine
- Dream Dive neural traversal

## Hard Constraint

Every ability must be explainable as neural interface, predictive modeling,
cybernetics, bioengineering, distributed computation, signal control, or memory
architecture. No ability can be magic.
